IDE: код и git

Откройте раздел через значок в левой колонке. Если значка нет, включите модуль через ⊞ → Модули. Кнопка ! открывает краткую справку прямо в программе.

  <p>Файлы открываются в предварительной вкладке (курсив): следующий файл заменяет её. Изменение файла или двойной клик закрепляет вкладку. Кнопка ◫ открывает соседнюю группу редактора; Ctrl+1 / Ctrl+2 переключают группы.</p>
  <p>Ctrl+P — открыть файл по имени, Ctrl+G — перейти к строке, Ctrl+Tab / Ctrl+Shift+Tab — переключить вкладку, Ctrl+B — скрыть дерево. Alt+↑/↓ — переместить строку, Shift+Alt+↑/↓ — копировать строку, Ctrl+Shift+K — удалить строку. Shift+Alt+F — terraform fmt.</p>
  <p>В консоли кнопка + (Ctrl+Shift+&#96;) создаёт второй терминал. Список «Терминал» переключает независимые сессии; скрытие панели их не завершает.</p>
  <h4>Как работает</h4>
  <p>Встроенный редактор кода с подсветкой синтаксиса (TypeScript/JavaScript, Python, Go, Rust, YAML, JSON, Terraform/HCL, SQL, Shell, Dockerfile, TOML, Markdown, HTML/CSS…), деревом проекта и панелью git.</p>
  <h4>Что где</h4>
  <ul>
    <li><b>📂</b> — выбрать папку проекта в системном окне (весь проект откроется деревом слева), <b>⌁</b> — взять папку, в которой сейчас терминал, <b>＋</b> — новый файл (путь с / на конце — папка). Недавние проекты — в списке под заголовком.</li>
    <li>В дереве цветом отмечены изменения git: жёлтый — изменён, зелёный — новый, красный — удалён.</li>
    <li><b>Правый клик в дереве</b> — создать файл или папку здесь, переименовать, скопировать и вставить (занятое имя получает «копия»), удалить. Корзины нет — удалённое возвращается только из git, поэтому OpsDeck спрашивает. Открытые вкладки следуют за переименованием. Работает только внутри папки проекта.</li>
    <li><b>⇢ AI</b> внизу справа — спросить ИИ о файле (или выделенном фрагменте), о проекте (структура и <code>git status</code>) или проверить изменения (<code>git diff</code>). Текст уходит в AI-панель терминала — выбранному агенту или локальному ИИ; вы дописываете вопрос и отправляете.</li>
    <li><kbd>Ctrl+S</kbd> — сохранить. Если файл поменяли снаружи после открытия, OpsDeck спросит, перезаписать ли его.</li>
    <li><b>Несколько проектов.</b> Открытые проекты показаны плашками над деревом: клик переключает, × закрывает. У каждого свои открытые файлы, раскрытые папки и выбранный файл. Для перехода к предыдущему или следующему проекту назначьте удобные сочетания в ⚙ → «Сочетания клавиш»; по умолчанию они не назначены. Конкретный проект можно выбрать в палитре команд (Ctrl+Shift+P). При несохранённых изменениях переход требует подтверждения.</li>
    <li><b>Поиск по всему проекту</b> — кнопка ⌘ слева вверху или <kbd>Ctrl+Shift+F</kbd> в том числе в редакторе: текст или регулярное выражение, с учётом регистра по галочке. Результаты сгруппированы по файлам, клик открывает нужную строку. Папки сборки и чужой код (.git, node_modules, target, dist, .terraform, vendor…), бинарные файлы и всё тяжелее 2 МБ пропускаются; показываются первые 500 совпадений.</li>
    <li><kbd>Ctrl+W</kbd> закрывает вкладку (в терминале — панель), а не окно приложения. <kbd>Ctrl+Z</kbd>, <kbd>Ctrl+Shift+Z</kbd>, <kbd>Ctrl+Y</kbd>, <kbd>Ctrl+A</kbd>, <kbd>Ctrl+D</kbd> и <kbd>Ctrl+/</kbd> работают на любой раскладке.</li>
    <li><kbd>Ctrl+F</kbd> — поиск и замена (как и <kbd>Ctrl+S</kbd>, работает на любой раскладке; из дерева тоже), <kbd>Ctrl+/</kbd> — закомментировать, <kbd>Tab</kbd> / <kbd>Shift+Tab</kbd> — отступ.</li>
    <li><kbd>Ctrl+=</kbd> / <kbd>Ctrl+−</kbd> или <kbd>Ctrl</kbd>+колесо — крупнее / мельче шрифт редактора, <kbd>Ctrl+0</kbd> — как было. Запоминается.</li>
    <li><b>▭ консоль</b> внизу (<kbd>Ctrl+`</kbd>) — терминал прямо в папке проекта: ↻ перезапустить, ⧉ открыть эту папку во вкладке терминала. При смене проекта консоль сама делает <code>cd</code> — если в ней ничего не выполняется (иначе OpsDeck скажет об этом и не будет набирать команду в программу).</li>
    <li><b>Размеры панелей</b> — потяните за границы между деревом, редактором, консолью и панелью git; двойной клик по границе — вернуть размер по умолчанию. Размеры запоминаются.</li>
    <li><b>⛓ pipeline</b> внизу справа (кнопка появляется, если в проекте есть <code>.gitlab-ci.yml</code> или <code>.github/workflows</code>) — граф пайплайна: колонки это стадии (у GitHub — порядок по <code>needs</code>), карточки это задачи. Сверху выбираются <b>событие</b> (push, merge request, тег, расписание, запуск вручную), <b>ветка</b>, список <b>изменённых файлов</b> (для <code>rules:changes</code> и <code>on: paths</code>) и переменные. Цвет карточки: зелёная — запустится, жёлтая — только вручную, серая — не запустится, фиолетовая — неизвестно (условие зависит от того, чего нет в файле). Клик по задаче показывает, какое правило сработало, «В файле» открывает её строку, «⇢ AI» отправляет задачу с условием в AI-панель. Галочка <b>сравнить с</b> показывает, чем отличается другая ветка. Раскрываются <code>include: local</code>, <code>extends</code>, якоря YAML и <code>!reference</code>; это разбор файлов, а не сам сервер — переменные проекта, защищённые ветки и дочерние пайплайны отсюда не видны.</li>
    <li><b>⎇ git</b> внизу справа — панель git: изменённые файлы (клик — дифф, двойной клик — открыть файл), поле коммита (<b>Закоммитить всё</b> = <code>git add -A</code> + commit, <kbd>Ctrl+Enter</kbd>) и граф коммитов всех веток (клик — коммит целиком).</li>
    <li><b>Жёлтая полоса слева от строки</b> — эта строка ещё не отправлена в удалённую ветку (сравнение с <code>@{upstream}</code>, а если ветка только локальная — с <code>origin/HEAD</code>). Обновляется при сохранении, переключении вкладок и после git-операций.</li>
    <li><b>Ветки</b> — кнопка с именем ветки вверху панели git: клик по ветке — переключиться (удалённая станет локальной с отслеживанием), <b>＋ Новая ветка</b> — от текущей, при наведении <b>⤵</b> — слить в текущую, <b>×</b> — удалить (для не слитой OpsDeck переспросит). <b>⟳</b> fetch, <b>↓</b> pull (только fast-forward), <b>↑</b> push (новая ветка уходит с <code>-u origin</code>). Открытые файлы после переключения перечитываются сами; если в них есть несохранённые правки, OpsDeck предупредит.</li>
    <li>В панели «Файлы» терминала и по <kbd>Ctrl</kbd>+клику на путь в выводе файлы открываются здесь, если там выбрана «OpsDeck IDE».</li>
  </ul>
  <h4>Проверка и форматирование</h4>
  <ul>
    <li><b>YAML</b> и <b>JSON</b> — ошибки синтаксиса подчёркиваются сразу, на полях слева значок; наведите мышь — текст ошибки.</li>
    <li><b>Terraform</b> (.tf, .tfvars, .hcl) — проверка через <code>terraform fmt</code> (или <code>tofu</code>), ошибки показываются на своих строках. При сохранении файл форматируется как <code>terraform fmt</code>; <kbd>Shift+Alt+F</kbd> или кнопка <b>fmt</b> — отформатировать сейчас. Без terraform в PATH проверяются только скобки и кавычки.</li>
  </ul>

Как проверить результат

После изменения настройки проверьте состояние или данные в этом же разделе. Если приложение показывает ошибку, прочитайте её до повторного действия. Журнал доступен в ⚙ → Журнал. Не публикуйте пароли, токены, kubeconfig и приватные ключи в отчётах.

Пошагово: два проекта и свои сочетания (dev)

  1. Откройте папку первого проекта, затем второго. Над деревом появятся плашки проектов.
  2. В ⚙ → Сочетания клавиш найдите IDE: предыдущий проект и IDE: следующий проект.
  3. Нажмите кнопку напротив действия и введите удобное сочетание. По умолчанию клавиши не назначены; Escape снимает назначение. Конфликт с другим назначаемым действием будет показан рядом.
  4. Вернитесь в IDE и нажмите назначенные клавиши. При несохранённых изменениях подтвердите переход либо отмените его и сохраните файл.
  5. Для выбора конкретного проекта откройте Ctrl+Shift+P и найдите Перейти в проект с его именем.

Пошагово: файлы рядом (0.9.2)

  1. Выберите файл в дереве: он откроется во вкладке предпросмотра.
  2. Дважды нажмите файл или вкладку, чтобы закрепить её. Изменение или сохранение также закрепляет вкладку.
  3. Нажмите ◫ в нижней полосе, чтобы открыть соседнюю группу, затем выберите другой файл.
  4. Кликните в нужный редактор перед вводом, поиском или сохранением. У групп независимая история отмены.
  5. Ctrl+P ищет файл по имени; Ctrl+G открывает ввод номера строки; Ctrl+Shift+F ищет содержимое по проекту.

В нижней полосе кнопка консоль показывает shell в каталоге проекта. + в заголовке консоли добавляет вторую сессию, список терминалов выбирает активную. Скрытие панели сохраняет запущенные сессии. Перед сменой проекта завершите интерактивную команду: приложение не вводит cd в работающую программу.
