Установка и первый запуск

← Wiki

Установка

Скачайте пакет для своей системы из GitHub Releases: .deb, .rpm или .AppImage для Linux, .msi или .exe для Windows, .dmg для macOS. Требования по версиям ОС и инструкции для неподписанной сборки macOS приведены в README.

Для сборки из исходников нужны Node.js 20+, Rust и системные зависимости Tauri. Команды и пакеты для Linux перечислены в README.

Первые действия

  1. Откройте ⚙ Настройки и проверьте язык, найденные пути KeePass, заметок и WinBox.
  2. Нажмите ⊞ в левой колонке и включите нужные модули. Выключенный модуль не загружается.
  3. Добавьте первое подключение в его разделе: SSH-хост, контекст Kubernetes или веб-панель. Порядок описан в Подключениях.
  4. Для рабочих и тестовых систем при необходимости создайте разные Окружения в настройках. У них раздельные хосты, кластеры, базы, панели, пароли keyring и раскладка.

Внешние программы

Некоторые функции используют программы, установленные на компьютере: ssh, sftp, scp для хостов и файлов, yc для Yandex Cloud, WinBox для роутеров, CLI AI-агентов для соответствующей AI-панели. Файловые панели требуют вход по SSH-ключу. Локальную AI-модель и её движок можно поставить отдельно из ⚙ → Локальный ИИ.

Если функция недоступна, проверьте, что нужная программа запускается в терминале из PATH, затем откройте подсказку ! в разделе.

Запуск без окна выбора окружения

  1. При старте отметьте Больше не показывать при запуске.
  2. Нажмите Открыть у нужного окружения. Запоминается именно окружение, которое вы открываете.
  3. При следующем обычном запуске оно откроется автоматически.
  4. Чтобы вернуть вопрос или выбрать другое окружение по умолчанию, откройте ⚙ → Окружения → При запуске открывать. Значение — спрашивать — возвращает выбор.

Это уже существующая настройка запуска. Галочка не удаляет другие окружения: открыть их можно из текущего рабочего места через Окружения….

Модули на небольшом экране

Нажмите ⊞ в левой колонке и прокрутите список колёсиком или тачпадом. Отметка включает раздел; снятие скрывает его, при следующем запуске его интерфейс не загружается. Левая колонка с включёнными разделами тоже прокручивается: если нижние значки не видны, наведите на неё мышь и прокрутите вниз.

Внешний вид и пояснения (dev)

⚙ → Внешний вид → Тема интерфейса предлагает тёмную, светлую и системную тему. Выбор применяется сразу и сохраняется. Системный вариант следует светлой или тёмной теме ОС. Цвета терминала задаются независимо в ⚙ → Терминал → Цветовая схема терминала.

Пояснения в настройках свёрнуты под Подробнее. Нажмите надпись, чтобы прочитать текст; повторный клик сворачивает его. Разворачивание не меняет настройку и не требует сохранения.
