# KeePass

Откройте раздел через значок в левой колонке. Если значка нет, включите модуль через **⊞ → Модули**. Кнопка **!** открывает краткую справку прямо в программе.


      <h4>Как работает</h4>
      <p>База .kdbx открывается только на чтение, расшифрованная живёт лишь в памяти. Пароль вводится один раз: база остаётся открытой до закрытия OpsDeck (в ⚙ можно вместо этого включить автоблокировку после простоя). Правки делайте в KeePassXC — OpsDeck заметит, что файл изменился, и через пару секунд перечитает его сам, без повторного ввода пароля. Если сменился мастер-пароль, перечитать не получится — появится сообщение; заблокируйте и откройте базу заново.</p>
      <h4>Что где</h4>
      <ul><li>👤 / 🔑 в строке — скопировать логин / пароль; пароль стирается из буфера через 30 секунд.</li>
      <li>Клик по строке — подробности: 👁 показать пароль на 10 секунд (повторное нажатие — скрыть), заметки записи.</li>
      <li>Записи KeePass можно привязать к веб-панелям, SSH-хостам и роутерам MikroTik — тогда пароли берутся отсюда.</li>
      <li>Пока база открыта, пароли есть в палитре <kbd>Ctrl+Shift+P</kbd> → «Пароль: …».</li></ul>

## Как проверить результат

После изменения настройки проверьте состояние или данные в этом же разделе. Если приложение показывает ошибку, прочитайте её до повторного действия. Журнал доступен в **⚙ → Журнал**. Не публикуйте пароли, токены, kubeconfig и приватные ключи в отчётах.
