# Алерты

Откройте раздел через значок в левой колонке. Если значка нет, включите модуль через **⊞ → Модули**. Кнопка **!** открывает краткую справку прямо в программе.


      <h4>Как работает</h4>
      <p>OpsDeck сам опрашивает источники (раз в минуту, настраивается в ⚙) — на этот компьютер извне ничего не приходит, так что IP и NAT не важны. Источники заводятся в «Веб-панелях» (◎):</p>
      <ul>
        <li><b>Grafana</b> — алерты Grafana Alerting (логин/пароль, токен service account с ролью Viewer или KeePass);</li>
        <li><b>Alertmanager</b> — Prometheus Alertmanager;</li>
        <li><b>Zabbix</b> — проблемы Zabbix 6.0+ по API, те же, что на его странице Problems (без выключенных хостов и триггеров, зависимых и «симптомов»): API-токен (Users → API tokens) или логин/пароль; если веб-сервер перед Zabbix спрашивает пароль (HTTP Basic) — заполните «Basic auth» в коннекторе (на 7.2+ за Basic — только логин/пароль, через сессию входа в веб-интерфейс: это обходной путь);</li>
        <li><b>AI / анализатор</b> — находки вашего анализатора логов/алертов: локальный присылает их на 127.0.0.1 со своим токеном, удалённый отдаёт JSON-ленту по URL.</li>
      </ul>
      <h4>Алерты на телефон: ntfy и Gotify</h4>
      <p>В ⚙ раздела: <b>На телефон</b> → ntfy или Gotify. Уходят те же алерты, что и уведомления на рабочем столе (без скрытых и заглушенных; восстановление — если включено «…и о восстановлении»), первые пять по одному, остальные одной сводкой; critical — с наивысшим приоритетом, по нажатию открывается дашборд.</p>
      <ul>
        <li><b>ntfy</b>: сервер (<code>https://ntfy.sh</code> или свой) и топик — придумайте длинный, его знание и есть доступ; в приложении ntfy подпишитесь на тот же топик. Для закрытого топика — токен доступа <code>tk_…</code>.</li>
        <li><b>Gotify</b>: адрес сервера и токен приложения (Apps → Create application).</li>
      </ul>
      <p><b>Отправить проверку</b> шлёт одно сообщение с сохранёнными настройками. Токен хранится в системном keyring.</p>
      <h4>Как подключить Grafana — по шагам</h4>
      <ol>
        <li>В Grafana ничего настраивать не нужно: ни contact point, ни webhook. Нужен только доступ на чтение.</li>
        <li>В Grafana: <b>Administration → Users and access → Service accounts → Add service account</b>, имя <code>opsdeck</code>, роль <b>Viewer</b> → Create.</li>
        <li>На странице аккаунта: <b>Add service account token → Generate</b>, скопируйте токен <code>glsa_…</code> (показывается один раз).</li>
        <li>Здесь: кнопка <b>＋ Grafana</b> (или ◎ → ＋ Добавить → тип Grafana), URL как в браузере, Авторизация = <b>токен</b>, вставить → <b>Сохранить и проверить</b>. Увидите «✓ Работает: активных алертов N» или причину ошибки.</li>
      </ol>
      <p>Токен даёт только сбор алертов. Чтобы Grafana ещё и открывалась вкладкой с автовходом — выберите «логин/пароль» или запись KeePass.</p>
      <h4>Если ошибка</h4>
      <ul>
        <li><b>401</b> — неверный токен/пароль; <b>403</b> — мало прав (нужна роль Viewer);</li>
        <li><b>404</b> — в Grafana не включён Grafana Alerting, или алерты живут в Prometheus Alertmanager — тогда добавьте коннектор Alertmanager;</li>
        <li><b>нет соединения</b> — URL недоступен с этого компьютера (VPN?).</li>
      </ul>
      <h4>Что где</h4>
      <ul>
        <li>Число на колокольчике слева — горящие алерты (без просмотренных, заглушённых и скрытых).</li>
        <li>Разделы по давности: <b>🆕 Новые</b> (за 24 часа), <b>За неделю</b>, <b>Давно горят</b> (больше 7 дней — обычно фон), <b>Просмотренные и заглушённые</b>. Разделы сворачиваются, состояние запоминается.</li>
        <li>Одинаковые алерты (одно правило из одного источника) собраны в одну карточку со счётчиком <b>×N</b>; в «экземплярах» видно, чем они отличаются (instance, pod…).</li>
        <li>Фильтры сверху: severity (клик — только она, повторный клик — все), источник, поиск по имени/меткам/тексту.</li>
        <li><b>🔕 Скрыть такие</b> — убрать мусорный алерт (по имени и источнику) из списка, счётчика и уведомлений. Вернуть: ⚙ → «Скрытые алерты».</li>
        <li>Кнопки карточки: <b>Панель / Дашборд / Правило / Silence</b> открываются во встроенной вкладке Grafana; <b>⇢ AI</b> — разобрать алерт в Claude; <b>✓ Просмотрен</b> — убрать из счётчика; у находок AI — <b>Закрыть</b>.</li>
        <li><b>↻ Опросить</b> — сейчас; ошибки источников показываются красной строкой сверху.</li>
        <li>Пропавший из источника алерт становится resolved и уходит в историю.</li>
      </ul>

## Как проверить результат

После изменения настройки проверьте состояние или данные в этом же разделе. Если приложение показывает ошибку, прочитайте её до повторного действия. Журнал доступен в **⚙ → Журнал**. Не публикуйте пароли, токены, kubeconfig и приватные ключи в отчётах.
