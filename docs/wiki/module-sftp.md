# Файлы на хостах

Откройте раздел через значок в левой колонке. Если значка нет, включите модуль через **⊞ → Модули**. Кнопка **!** открывает краткую справку прямо в программе.


      <h4>Что это</h4>
      <p>Две панели для обмена файлами (#78): в каждой — либо эта машина, либо хост по SSH. Выделите файлы и нажмите <b>→</b> или <b>←</b>. Работает через системные <code>sftp</code> и <code>scp</code>, то есть через тот же OpenSSH, что и терминал: применяются <code>~/.ssh/config</code>, ProxyJump и ключи.</p>
      <h4>Как пользоваться</h4>
      <ul><li>Модуль включается галочкой в меню ⊞ внизу колонки слева.</li>
      <li>Сверху панели — <b>где смотрим</b> (эта машина, профиль SSH, хост из ~/.ssh/config), путь можно вписать руками, ↑ — на уровень выше, двойной клик по папке — войти.</li>
      <li>Клик по заголовку колонки меняет порядок: по имени, размеру или дате изменения; папки всегда сверху. У даты и размера первый клик ставит наверх самое свежее и крупное.</li>
      <li>После копирования перенесённое выделяется в панели-приёмнике — сразу видно, что приехало.</li>
      <li>Клик выделяет, <kbd>Ctrl</kbd>+клик добавляет к выделению. Снизу — создать папку, переименовать, удалить (папка удаляется со содержимым).</li>
      <li><b>Хост → хост</b> идёт через <code>scp -3</code>: оба соединения ведёт OpsDeck, хостам не нужно видеть друг друга и ключи остаются у вас. Если у хоста нестандартный порт, свой ключ или jump-хост, scp не сможет развести опции по концам — скачайте файлы к себе, потом загрузите.</li></ul>
      <h4>Вход</h4>
      <p>Только по ключу (<code>BatchMode</code>): пароль <code>sftp</code> читает с терминала, а в пакетном режиме его взять негде. Если хост просит пароль — добавьте ключ (<code>ssh-copy-id</code>) или укажите его в профиле SSH. Ключ хоста должен быть уже принят: подключитесь к нему один раз из терминала.</p>

## Как проверить результат

После изменения настройки проверьте состояние или данные в этом же разделе. Если приложение показывает ошибку, прочитайте её до повторного действия. Журнал доступен в **⚙ → Журнал**. Не публикуйте пароли, токены, kubeconfig и приватные ключи в отчётах.
