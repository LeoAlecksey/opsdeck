# Установка и первый запуск

[← Wiki](README.md)

## Установка

Скачайте пакет для своей системы из [GitHub Releases](https://github.com/LeoAlecksey/opsdeck/releases): `.deb`, `.rpm` или `.AppImage` для Linux, `.msi` или `.exe` для Windows, `.dmg` для macOS. Требования по версиям ОС и инструкции для неподписанной сборки macOS приведены в [README](../../README.md#установка).

Для сборки из исходников нужны Node.js 20+, Rust и системные зависимости Tauri. Команды и пакеты для Linux перечислены в [README](../../README.md#сборка-из-исходников).

## Первые действия

1. Откройте **⚙ Настройки** и проверьте язык, найденные пути KeePass, заметок и WinBox.
2. Нажмите **⊞** в левой колонке и включите нужные модули. Выключенный модуль не загружается.
3. Добавьте первое подключение в его разделе: SSH-хост, контекст Kubernetes или веб-панель. Порядок описан в [Подключениях](connections.md).
4. Для рабочих и тестовых систем при необходимости создайте разные **Окружения** в настройках. У них раздельные хосты, кластеры, базы, панели, пароли keyring и раскладка.

## Внешние программы

Некоторые функции используют программы, установленные на компьютере: `ssh`, `sftp`, `scp` для хостов и файлов, `yc` для Yandex Cloud, WinBox для роутеров, CLI AI-агентов для соответствующей AI-панели. Файловые панели требуют вход по SSH-ключу. Локальную AI-модель и её движок можно поставить отдельно из **⚙ → Локальный ИИ**.

Если функция недоступна, проверьте, что нужная программа запускается в терминале из `PATH`, затем откройте подсказку **!** в разделе.
