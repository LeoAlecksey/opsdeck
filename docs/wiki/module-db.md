# Базы данных

Откройте раздел через значок в левой колонке. Если значка нет, включите модуль через **⊞ → Модули**. Кнопка **!** открывает краткую справку прямо в программе.


      <h4>Как работает</h4>
      <p>Подключения к PostgreSQL, MySQL/MariaDB, ClickHouse, Redis и MongoDB: адрес, порт, логин. Пароль хранится в системном keyring или берётся из записи KeePass или Passbolt. Слева структура: базы → схемы → таблицы → колонки и индексы (у Redis — db и ключи, у MongoDB — коллекции, поля и индексы). Справа редактор запросов и результат.</p>
      <h4>Что где</h4>
      <ul>
        <li><b>＋</b> — новое подключение. <b>Сохранить и проверить</b> сразу показывает версию сервера или ошибку.</li>
        <li><b>Через SSH-хост (jump)</b> — если база доступна только с бастиона: выберите хост из профилей SSH или <code>~/.ssh/config</code> (там же работают <code>ProxyJump</code> и ключ), и OpsDeck поднимет туннель <code>ssh -L</code> сам. Нужен вход по ключу, как в мониторинге; шифрование «verify» через туннель не работает — выберите «require».</li>
        <li>Наведите мышь на подключение: <b>↻</b> — перечитать структуру, <b>✎</b> — изменить, <b>×</b> — удалить.</li>
        <li>Клик по базе или таблице выбирает базу, в которой выполняется запрос (поле <b>«в»</b> вверху). Двойной клик по таблице, коллекции или ключу — сразу показать первые строки.</li>
        <li><kbd>Ctrl+Enter</kbd> — выполнить. Если что-то выделено, выполняется только выделенное. Показываются первые 1000 строк.</li>
        <li><b>История</b> — последние 50 запросов этого подключения; черновик запроса сохраняется сам.</li>
        <li>Двойной клик по ячейке — скопировать значение; <b>CSV</b> / <b>JSON</b> — скопировать весь результат. У MongoDB есть вид <b>JSON</b> с документами целиком.</li>
        <li>Высоту редактора меняет полоска между ним и результатом.</li>
      </ul>
      <h4>Синтаксис</h4>
      <ul>
        <li><b>SQL</b> (PostgreSQL, MySQL, ClickHouse) — как обычно, можно несколько запросов через <code>;</code> — показывается результат последнего.</li>
        <li><b>Redis</b> — команды по одной в строке, как в redis-cli: <code>HGETALL user:1</code>, <code>SCAN 0 MATCH sess:* COUNT 100</code>.</li>
        <li><b>MongoDB</b> — как в mongosh: <code>db.users.find({ age: { $gt: 30 } }).sort({ name: 1 }).limit(20)</code>, <code>aggregate([...])</code>, <code>countDocuments</code>, <code>distinct</code>, <code>insertOne</code>, <code>updateMany</code>…, команда <code>{ serverStatus: 1 }</code>, <code>show dbs</code>, <code>show collections</code>.</li>
      </ul>
      <h4>Только чтение</h4>
      <p>Галочка в подключении для прод-баз. PostgreSQL и ClickHouse запрещают запись на стороне сервера; для MySQL, Redis и MongoDB выполняются только читающие запросы и команды. На подключении — 🔒, над редактором — «только чтение».</p>

## Как проверить результат

После изменения настройки проверьте состояние или данные в этом же разделе. Если приложение показывает ошибку, прочитайте её до повторного действия. Журнал доступен в **⚙ → Журнал**. Не публикуйте пароли, токены, kubeconfig и приватные ключи в отчётах.
