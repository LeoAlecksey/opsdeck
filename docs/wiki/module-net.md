# Сеть и DNS

Откройте раздел через значок в левой колонке. Если значка нет, включите модуль через **⊞ → Модули**. Кнопка **!** открывает краткую справку прямо в программе.


      <h4>Как работает</h4>
      <p>Запускаются системные утилиты, вывод идёт построчно. Опасные аргументы отсекаются — в поле адреса нельзя передать опцию.</p>
      <h4>Что где</h4>
      <ul><li>Вкладка <b>Утилиты</b>: ping, mtr (отчёт), traceroute, dig, nslookup, проверка одного TCP-порта.</li>
      <li>Вкладка <b>Порты</b>: скан портов хоста (список и диапазоны, например <code>22,80,8000-8100</code>, или готовые наборы) — открыт / закрыт / фильтруется и что отвечает (баннер сервиса, заголовок Server, TLS); ниже — какие порты слушает эта машина и какой процесс их держит.</li>
      <li>Для DNS можно указать тип записи и сервер (например 8.8.8.8), для ping/mtr — число пакетов.</li>
      <li><b>Стоп</b> прерывает долгую команду.</li></ul>

## Как проверить результат

После изменения настройки проверьте состояние или данные в этом же разделе. Если приложение показывает ошибку, прочитайте её до повторного действия. Журнал доступен в **⚙ → Журнал**. Не публикуйте пароли, токены, kubeconfig и приватные ключи в отчётах.
