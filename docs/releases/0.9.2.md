# OpsDeck 0.9.2 — удобнее работать в IDE

## Файлы и навигация

- Быстрый поиск файла по имени через Ctrl+P (Cmd+P на macOS).
- Один клик открывает файл для предпросмотра; двойной клик, редактирование или сохранение закрепляет вкладку.
- Переход к строке через Ctrl+G, переключение файлов через Ctrl+Tab и скрытие дерева проекта через Ctrl+B.
- Поиск по проекту через Ctrl+Shift+F теперь работает и внутри редактора. Форматирование Terraform перенесено на Shift+Alt+F и по-прежнему выполняется при сохранении.
- Добавлены перемещение, копирование и удаление строк с клавиатуры.

## Две группы редактора и консоли

- Открывайте файлы рядом в двух группах редактора и переключайте фокус между ними.
- В IDE можно держать две консоли и выбирать нужную в списке.
- Исправлена работа с состоянием файлов при переключении групп, быстром открытии, форматировании и сохранении.

## Kubernetes Secrets

Значение отдельного ключа можно изменить или вставить из буфера. Пробелы и переносы строк сохраняются, другие ключи не затрагиваются. Если Secret изменился на сервере, устаревшее сохранение отклоняется. В режиме только чтения редактирование недоступно.

Также обновлены зависимости Rust и встроенная справка.
