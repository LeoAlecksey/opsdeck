## OpsDeck 0.6.2 — история событий Kubernetes, kubeconfig из папок и исправления от сообщества

Снова по вашим issues и PR — спасибо всем! 🙌

### ✨ Новое
- **История событий Kubernetes.** Kubernetes хранит события около часа — к утру «что упало ночью» уже не узнать. Кнопка «Записывать события этого кластера»: пока OpsDeck открыт, он слушает события всех namespace и хранит их неделю, повторы складываются в одну строку (×N). В «Кластер → История событий» сверху — что падало чаще всего за 24 часа, строка открывает сообщение и «⇢ AI». (#55, идея — @shafiev)
- **kubeconfig из папок, как во Freelens.** ⚙ → Kubernetes → «＋ Папка…»: все kubeconfig из папки (и подпапок) появляются в списке кластеров и читаются на месте, без копирования. (#44, идея — @alexei-dmitriev)
- **SSH-конфиг:** `Include` (с масками), комментарии в конце строк и `ProxyCommand` в `~/.ssh/config`. *(@artp1ay)*
- **Kubernetes на нестабильной сети:** таймаут подключения 15 с, при обрыве — «повторное подключение» вместо ошибки, скелетон таблицы при загрузке. *(@artp1ay)*
- **Заметки:** проверка пути к хранилищу, «Обзор…», понятные экраны «папка не найдена» и «пусто». Если папки сейчас нет (сетевой диск не подключён), остальные настройки всё равно сохраняются. *(@artp1ay)*

### 🛠 Исправления
- Внешний ИИ: адрес, скопированный с `/v1` (или целиком `/v1/chat/completions`), больше не даёт HTTP 404. (#58, спасибо @texoff)
- Строка ресурсов узнаёт SSH-сессию в любой записи: `ssh host -p 2222`, `-p2222`, флаги группой. *(@LockerWarUA)*
- Меню модулей ⊞ больше не перекрывается открытой веб-панелью; одна веб-панель не создаётся дважды. *(@LockerWarUA)*
- Вкладка WSL не получает вместо имени путь к `wsl.exe`. *(@LockerWarUA)*
- KeePass: «👁» у пароля — переключатель, повторное нажатие прячет. *(@LockerWarUA)*
