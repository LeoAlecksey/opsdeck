## OpsDeck 0.7.1 — заметки и задачи на Windows, Enter в диалогах и шесть исправлений от сообщества

Исправления по вашим отчётам после 0.7.0. Если вы на Windows и у вас перестали открываться заметки — обновитесь, это первый пункт. Спасибо всем, кто пишет! 🙌

### 🛠 Исправления

- **Заметки и задачи на Windows: «путь вне vault» на каждом файле.** Ни одна заметка не открывалась и ни одна задача не сохранялась. Причина: `canonicalize()` на Windows возвращает путь с префиксом `\\?\`, а папка заметок хранится без него — проверка «файл внутри хранилища» всегда была ложной. Появилось в 0.6.2. *(из Telegram-чата и #76)*
- **Enter в диалогах отменял вместо сохранения.** Браузер отправляет форму по Enter первой кнопкой, а в наших окнах первой стояла «Отмена»: окно закрывалось, введённое пропадало. Касалось веб-панелей, SSH, баз, MikroTik, сниппетов, задач, переноса настроек и всех подтверждений. *(#68, @DuraCHYo)*
- **Мониторинг на Windows** больше не советует «откройте сессию в OpsDeck»: у OpenSSH для Windows нет общего соединения (ControlMaster), поэтому там нужен вход по ключу — теперь так и написано, и в ошибке, и в подсказке раздела. *(#77, @RouR)*
- **Задачи: удаление.** В строке задачи появилась корзина: подтверждение, и строка убирается из заметки. Бэкенд сверяет, что на этой строке всё ещё та же задача. *(#76, @RouR; мультивыбор — в следующем релизе)*

### ⚡ От @LockerWarUA

- **Настройки больше не дёргают хранилище паролей** на таймерах заметок, задач и подсказок в терминале. На Linux каждое такое обращение — сессия Secret Service по D-Bus, а при заблокированной связке — возможное окно ввода пароля.
- **Без автопроверки обновлений приложение не ходит на сервер релизов.** С включённой галочкой — один запрос вместо двух; неудачная проверка теперь видна в настройках, а не теряется.
- **Окно не подвисает на старте** (~0,2 с): опрос ресурсов ушёл с главного потока.
- **Раздел SSH открывается быстрее**: `ssh -G` по хостам из `~/.ssh/config` выполняется в 8 потоков — на Windows со 100 хостами это было 2,3 секунды ожидания.
- **Правки в файлах, подключённых через `Include`**, теперь видны сразу: ключ кэша учитывает все прочитанные файлы, а не время изменения одного `~/.ssh/config`.
- **Вкладка терминала** больше не называется путём к `wsl.exe` или `powershell.exe`.

### 🧪 Для разработки

- У платформенных мест теперь есть тесты, которые идут на любой ОС: геометрия панели на macOS и текст про вход по ключу на Windows — чистые функции вместо проверок, которые раньше можно было увидеть только на самой системе.

### ⚠️ Про macOS

Полоса вкладок веб-панелей не в полноэкранном режиме (#68) **ещё не исправлена** — у нас нет Mac для проверки, а чинить вслепую второй раз не хочется. Если у вас macOS и есть желание помочь — напишите в #68, пришлём сборку.
