# OpsDeck 0.9.1 — меньше кликов, больше контроля

В этом обновлении собрали пожелания пользователей: настроили горячие клавиши, упростили работу с Kubernetes и добавили фоновый запуск команд для ИИ-агента.

## ⌨️ Свои сочетания клавиш — [#79](https://github.com/LeoAlecksey/opsdeck/issues/79), [#122](https://github.com/LeoAlecksey/opsdeck/issues/122)

Назначайте клавиши для перехода между модулями и разделами Kubernetes, открытия shell в поде, логов и port-forward. На macOS можно настроить привычное перемещение по строке и словам в терминале. Назначения сохраняются в настройках.

## ☸️ Удобнее работать с Kubernetes — [#79](https://github.com/LeoAlecksey/opsdeck/issues/79)

Переключайтесь между разделами с клавиатуры, открывайте логи и shell для выбранного объекта, запускайте port-forward. В Secrets нажмите на имя ключа, чтобы показать или скрыть значение, и скопируйте его в буфер.

## 🤖 Фоновые команды для ИИ-агента — [#98](https://github.com/LeoAlecksey/opsdeck/issues/98)

Разрешение на запуск команд через `&` вынесено в отдельную настройку и по умолчанию выключено. Такие команды считаются изменениями и требуют соответствующего уровня доступа.

Спасибо всем, кто присылает идеи и помогает делать OpsDeck удобнее. 💚
