## OpsDeck 0.9.0 — надёжнее SSH, без мигающей консоли в Windows

В этом выпуске — более предсказуемое подключение по SSH, спокойный запуск команд в Windows и обновления зависимостей.

### Исправления

- **Windows и ConPTY.** При открытии терминала, SSH, Kubernetes-команд и инструментов, работающих через псевдоконсоль, больше не должно мигать окно `conhost`.
- **SSH с выбранным ключом.** Если в профиле указан файл ключа, OpsDeck передаёт OpenSSH `IdentitiesOnly=yes`: другие ключи из `ssh-agent` не мешают выбранному ключу и не приводят к `Too many authentication failures`. Если ключ не задан, прежнее поведение с `ssh-agent` сохраняется.

### Зависимости и безопасность

- Обновлены npm- и Rust-зависимости и действие кэширования Rust в CI.
- Обновлены `quinn-proto` и `quinn-udp`, чтобы закрыть выявленные `cargo audit` уязвимости.
