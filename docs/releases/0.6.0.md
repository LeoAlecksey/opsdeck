## OpsDeck 0.6.0 — Windows как дома, доска мониторинга, импорт из WinBox и Zabbix

Большой релиз по вашим отзывам из Telegram-чата и issues. Спасибо всем, кто писал, тестировал и присылал PR! 🙌

🌐 Сайт с обзором и инструкцией: https://leoalecksey.github.io/opsdeck/

### ✨ Новое
- **Доска мониторинга хостов.** Новый модуль (включается в ⊞): карточки SSH-хостов с CPU, load, памятью, диском и аптаймом, по группам. Цвет карточки по худшему показателю: жёлтый от 75%, красный от 90%. Хосты берутся из раздела SSH и `~/.ssh/config`. Метрики снимаются по ssh-ключу или через уже открытую сессию; пароль доска не спрашивает. Только Linux-хосты.
- **Импорт роутеров из WinBox.** «Импорт из WinBox» в разделе MikroTik читает список адресов WinBox (Addresses.cdb): адрес и порт, логин, группу, заметку. Перед добавлением показывается список, уже добавленные пропускаются, пароли по галочке уходят в системное хранилище паролей. 40 роутеров — в два клика.
- **Алерты из Zabbix.** Новый источник: Zabbix 6.0–7.4+, API-токен или логин/пароль. Видно то же, что на странице Problems самого Zabbix: без отключённых хостов и триггеров, зависимых проблем и «симптомов». *(@LockerWarUA — поддержка Zabbix 7.2+, одна сессия вместо входа на каждом опросе, совпадение со страницей Problems)*
- **Цветовые схемы терминала.** OpsDeck, Campbell, One Half Dark, Solarized Dark, Dracula или своя: «Импорт JSON…» принимает settings.json Windows Terminal, список схем или одну схему. Применяется сразу ко всем терминалам.
- **AI-агент по умолчанию.** В настройках выбирается агент (Claude Code, Codex, Gemini, Aider, OpenCode): он открывается в AI-панели, получает выделенный текст, логи и алерты. Кнопка «@» в заметках отправляет ссылку на заметку выбранному агенту. *(@artp1ay)*
- **Переключение вкладок терминала** с клавиатуры: Alt+1…9, Alt+←/→, Ctrl+Tab, Ctrl+PageUp/PageDown (#26).
- **Веб-панели:** «＋» в полосе вкладок открывает ещё одну панель (например, вторую Grafana) без возврата к списку.

### 🪟 Windows
- **Блок «Windows» в настройках** (на Linux и macOS его не видно): выбор оболочки для новых вкладок — PowerShell 5.1 или 7, Git Bash, cmd, дистрибутив WSL — и импорт цветовых схем прямо из установленного Windows Terminal.
- **Кнопка WSL** рядом с ＋ в терминале открывает вкладку выбранного дистрибутива. Во вкладку WSL передаются нужные переменные (KUBECONFIG с переводом путей), ИИ знает, что там Linux, а разделение открывает тот же дистрибутив. *(@LockerWarUA)*
- **Интеграция с PowerShell:** блоки команд, серые подсказки продолжения, история PowerShell в подсказках. Git Bash распознаётся.
- IDE и панель файлов видят git-репозиторий (пути `C:/` и `C:\` сравниваются правильно); если git не установлен или папке нет доверия, показывается понятная ошибка.
- Заметки и файлы с переносами строк Windows больше не считаются изменёнными и сохраняются в своём формате.
- WinBox: путь в кавычках («Копировать как путь») или папка тоже работают.
- «⧉ в отдельном окне» у веб-панелей больше не зависает. *(@LockerWarUA)*

### 🍎 macOS
- zsh запускается как login shell с `~/.zprofile`, приложение видит полный PATH (Homebrew, `~/.local/bin`), ssh-сессии с пробелами в пути работают. *(@artp1ay)*

### 🐧 Linux

### 🛠 Исправления и мелочи
- Заметки: бирюзовая рамка вокруг несохранённой заметки.
- IDE: в графе git пояснение для новой ветки без своих коммитов.
- После Ctrl+Shift+K курсор больше не возвращается в терминал посреди ввода запроса.
- Английский интерфейс: убраны оставшиеся русские надписи, даты по языку приложения.

### 🧪 Надёжность
- Автотесты: Rust на Linux, Windows и macOS, тесты интерфейса (vitest + Playwright), сквозные тесты настоящего приложения на Linux и Windows. Релиз публикуется, только если все тесты зелёные.
- Статический анализ: clippy и CodeQL. Защита PR: проверка, что ссылки автора на донат и Telegram не подменены, метка «⚠ безопасность» для PR, трогающих CI, релизы и зависимости.
