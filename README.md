**Рабочее место DevOps-инженера для Linux, Windows и macOS.** Терминал с AI, Kubernetes, SSH, IDE с git, базы данных, веб-панели, алерты, заметки, задачи и хранилища паролей — в одном приложении.

**[📖 Подробная Wiki — установка, настройка и работа со всеми разделами](https://leoalecksey.github.io/opsdeck/wiki/)**

## Установка и обновления

Скачайте пакет для своей ОС из [Releases](https://github.com/LeoAlecksey/opsdeck/releases/latest). Требования, инструкции установки и сборки — в [руководстве](docs/wiki/reference.md). Обновление из приложения: **⚙ → Обновления**.

## Начало работы

1. Включите нужные разделы кнопкой **⊞**.
2. Добавьте SSH-хост, kubeconfig или другое подключение в соответствующем разделе.
3. Кнопка **!** открывает справку, **Ctrl+Shift+P** — палитру команд.
